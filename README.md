# 🪄 Phantomkit

Phantomkit is a fun and interactive Python toolkit that combines computer vision, speech recognition, and sentiment analysis with a Harry Potter-inspired twist! Featuring a modern GUI built with `tkinter`, this project lets you play with:

- 🧥 **Invisibility Cloak**
- ⏳ **Time Turner Effect**
- 🗣️ **Voice-based Sentiment Analysis**

---

## 🎬 Features

### 🧥 Invisibility Cloak
Create a live invisibility effect by masking red/blue/green cloaks in real-time using OpenCV.

### ⏳ Time Turner
Record 10 seconds of webcam video and rewind it in reverse — like turning back time.

### 🎙️ Voice Sentiment Analysis
Speak into the mic and get real-time feedback on whether your tone is positive, negative, or neutral using TextBlob.

---

## 🛠️ Tech Stack

- `Python 3.7+`
- `OpenCV`
- `SpeechRecognition`
- `TextBlob`
- `Tkinter` (GUI)
- `NumPy`
